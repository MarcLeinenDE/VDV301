Strongest attempted disproof: Could `GetDeviceConfiguration` legitimately set the device-ID despite its name? **No**: on V1.0 EN/Base V2.0/Base V2.1 the adjacent `SetDeviceConfiguration` explicit request (not Get response) handles the writing. The original V1.0 German correctly says *abzufragen*; the English edition's wrong setter sentence was carried forward. Later DMS V2.2/V2.4 continue to call Get a setter but visibly document a Get response; the V2.2 schema does not offer the old Set operation, so merely citing the old setter would be factually wrong. The interpretation also cannot be salvaged by operation name or a TOC cross-reference. No contradictory executable evidence observed; this is misleading PDF semantics and must not change XML PASS/FAIL.
